Developer Questions

Frequently Asked Questions

Straight answers on how PawTest works with Lighthouse, CI/CD, Claude Code, and Cursor.

How is PawTest different from Google Lighthouse?+

Google Lighthouse evaluates speed, basic accessibility, and SEO for human visitors. PawTest covers those core human UX checks and adds 2026 AI agent readiness probes: WAF fingerprinting (Cloudflare, DataDome, Akamai, PerimeterX), Markdown Token-Tax, DOM vs. JSON-LD price parity, W3C WebMCP schemas, HTTP 402/x402, and indirect prompt injection scanning.

Does PawTest require an OpenAI or Anthropic API key?+

No. PawTest runs 100% deterministic code locally against your installed Chrome, Edge, or Brave browser over raw Chrome DevTools Protocol (CDP). Zero runtime npm dependencies, zero cloud uploads, and $0 LLM API cost.

How do I connect PawTest to Claude Code or Cursor via MCP?+

Run npx pawtest --mcp or add it to your MCP server config. It exposes three lean tools (pawtest_audit, pawtest_cat, and pawtest_fix_prompt) so your AI coding assistant can audit localhost, generate ready-to-commit scaffolds, and re-verify fixes automatically.

How can I check if my site accidentally blocks AI shopping or search agents?+

Run npx pawtest https://your-site.com --full. PawTest evaluates RFC 9309 tiered crawler policies, Cloudflare Content-Signal, seven /.well-known/ manifests (UCP, ACP, AP2, A2A, MCP, RFC 9421), and detects active anti-bot challenges.
