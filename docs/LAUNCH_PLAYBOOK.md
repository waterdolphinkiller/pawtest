# PawTest Phase 4 Launch Playbook

Everything needed to run final real-world verification, publish to npm, and launch across developer communities.

## 1. Pre-Flight Verification Checklist (Run on a Networked Machine)

```bash
# 1) Full unit + E2E + MCP closed-loop + Dogfood S-tier check
npm test
npm run verify:mcp
npm run dogfood

# 2) Phase 3 real-world 5-site stress test (read-only --full)
npm run stress:real

# 3) Verify npm package tarball contents before publishing
npm pack --dry-run
npm publish --access public
```

## 2. Claude Code / Cursor MCP Configuration (`.mcp.json`)

Drop this into your project root `.mcp.json` (Claude Code) or `~/.cursor/mcp.json` (Cursor):

```json
{
  "mcpServers": {
    "pawtest": {
      "command": "npx",
      "args": ["-y", "pawtest", "--mcp"]
    }
  }
}
```

Verification prompt inside Claude Code / Cursor:
> "Use `pawtest_audit` on `http://localhost:3000`, read `pawtest_fix_prompt`, apply the fixes to my code, then re-run `pawtest_cat` on the failing cats until they turn green."
